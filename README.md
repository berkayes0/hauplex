# Hauplex web sitesi

Statik site. Sayfalar `_build/` altındaki kaynaklardan üretilir:

```
python3 _build/build.py
```

HTML dosyalarını doğrudan düzenlemeyin; `_build/parts/`, `_build/demos/` veya `_build/build.py` içinde değiştirip yeniden üretin. Yayın GitHub Pages üzerinden (main dalı, kök klasör). `_` ile başlayan klasörler Pages tarafından yayınlanmaz. İletişim formu FormSubmit ile `iletisim` formundaki `data-to` adresine gider.
